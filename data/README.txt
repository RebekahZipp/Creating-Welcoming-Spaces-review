DATA DIRECTORY — CONFIDENTIAL WORKING DATA NOT INCLUDED

The local editorial Shiny application expects an authorized working copy of the chapter-proposal workbook in this directory.

Do not commit or distribute the proposal workbook through this public repository.

The repository .gitignore excludes spreadsheet, CSV, ZIP, and other working data files as well as all contents of data/ except this README.

Public examples should use synthetic, de-identified, or otherwise explicitly shareable data.
